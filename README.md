# Yatra Travel Website

A simple static travel website featuring home, best deals, family tours, and honeymoon pages.

## 📁 Project Structure

- `index.html` — Homepage
- `pages/` — Additional pages (best deals, family tours, honeymoon)
- `css/` — Stylesheets for each page
- `images/` — Image assets used by the site

## 🚀 Run Locally
1. Open `index.html` in your browser.
2. Or serve the folder with a simple static server (recommended for best path handling):
   - Python: `python -m http.server 8000`
   - Node: `npx serve .`

## 📱 Responsive Design
Media queries are included in CSS files so the layout adapts for tablet and mobile screen sizes.

## ✨ Tips
- Edit styles in `css/*.css`.
- Add new pages inside `pages/` and link from the navigation in `index.html`.
